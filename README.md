This repository contains firmware for the Kits 4 Hams K4H818 radio module.  This module uses an ATMega 328P microcontroller.  The firmware is contained in a .hex file.  The entries in the repo are of the form K4H818_fw_revision number.hex
The latest revision of the firmware is also hosted in the repo as K4H818_fw_latest.hex
In HamVOIP change to the /etc/asterisk directory and then run K4H818-update to update to the latest firmware
In ASL3 run ./K4H818-update.py to update to the latest firmware
